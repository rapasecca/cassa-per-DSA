# Cassa Veloce Pro

Piccola app web per calcolare il resto, visualizzare i tagli di banconote/monete e installare la cassa sulla schermata Home di iPhone o Android.

## Pubblicazione con GitHub Pages

1. Apri **Settings → Pages** nel repository.
2. In **Build and deployment**, seleziona **Deploy from a branch**.
3. Seleziona il branch `main` e la cartella `/ (root)`, quindi premi **Save**.
4. Attendi la pubblicazione e apri l'indirizzo Pages mostrato nella stessa pagina. La prima pubblicazione può richiedere qualche minuto.

L'app richiede HTTPS per l'installazione e per la modalità offline; GitHub Pages lo fornisce automaticamente.

## Installazione su telefono

- **iPhone/iPad:** apri l'indirizzo Pages in Safari, tocca **Condividi** e scegli **Aggiungi alla schermata Home**.
- **Android:** apri l'indirizzo in Chrome e scegli **Installa app** dal menu o dal messaggio di installazione.

Dopo la prima visita, l'app può essere avviata dalla schermata Home e funziona anche offline. Non serve installare un pacchetto separato dallo store.
